# 📄 Resume IQ — AI-Powered Resume Analyzer

Resume IQ is a web-based resume analysis tool designed to help job seekers improve their resumes with structured feedback, resume scoring, and actionable suggestions based on modern resume-writing best practices.

🚀 **Live Demo:** https://soniyashaik29.github.io/Ai-resume-analyser/

## ✨ Features

- 📤 **Resume Upload** — Upload a resume using drag-and-drop or file selection.
- 📁 **Multiple File Formats** — Supports PDF, DOCX, and TXT files.
- 📏 **File Size Validation** — Supports files up to 5 MB.
- 📊 **Resume Scoring** — View a score out of 100 to assess resume quality.
- 📝 **Content Analysis** — Get feedback on resume clarity, structure, and impact.
- 🎯 **Actionable Suggestions** — Discover ways to improve your resume and work toward a stronger score.
- 📈 **Word Count** — View the number of words in your resume.
- 💻 **Web-Based Interface** — Access the application directly through your browser.

## 🎯 Project Objective

The main objective of Resume IQ is to help students, fresh graduates, and job seekers understand how to improve their resumes before applying for jobs.

The application aims to make resume improvement easier by providing structured feedback, highlighting areas for improvement, and presenting suggestions in a simple and accessible interface.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git
- A code editor, such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/soniyashaik29/Ai-resume-analyser.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Ai-resume-analyser
   ```

3. Open the project in Visual Studio Code or your preferred editor.

4. Run the application using your editor's local development server, if applicable, or open the main HTML file in your browser.

> Note: If your project uses a framework or build tool, follow the installation and run commands specified in its configuration files.

## 📖 How to Use

1. Open the [Resume IQ application](https://soniyashaik29.github.io/Ai-resume-analyser/).
2. Upload your resume in PDF, DOCX, or TXT format.
3. Ensure the file size does not exceed 5 MB.
4. Click **Analyze resume**.
5. Review the displayed resume score and feedback.
6. Follow the suggestions to improve the clarity, structure, and impact of your resume.

## ⚠️ Current Limitations

- Resume feedback is described by the live application as simulated AI-generated feedback rather than a verified connection to a live AI model.
- The analysis should be treated as guidance, not as a guarantee of ATS compatibility or job selection.
- Supported file formats and file-size limits may affect which resumes can be processed.
